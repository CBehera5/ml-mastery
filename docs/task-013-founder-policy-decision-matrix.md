## Normative bounds attached to E4

- Displayed snippets ≤25 lines/4 KiB; authored loop trace ≤32 steps; no learner execution.
- Arrays rank 0–2, each dimension ≤32, ≤64 total cells; tables ≤32 rows×8 columns, fixture strings ≤120 characters.
- ≤8 pipeline stages/slots/options per slot; ≤8 accepted whole tuples; ≤64 authored experiment configurations, **not** execution of every answer combination.
- Atom ≤512 bytes/8 fields; ≤2 atoms per family; family ≤1.5 KiB; ≤32 families plus ≤16-KiB framing; total submission ≤64 KiB; depth ≤8.
- Slot IDs ≤16 ASCII characters, option IDs ≤24, definition IDs ≤128. Numeric input magnitude ≤1e6, integer exponent 0–4, authored intermediate magnitude ≤1e12.
- Envelope allocation: summaries 40 KiB + active draft 64 + latest full submission 64 + evidence/policy references 32 + counters/metadata 16 =216 KiB, leaving 40 KiB headroom. Reject over-limit writes; do not silently truncate mastery.
