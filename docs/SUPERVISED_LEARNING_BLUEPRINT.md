## Depth and lesson contract

For every lesson, author in this order:

1. A realistic question and the reason the concept exists; prerequisite recall links.
2. A plain-language mechanism and an accessible geometric/data explanation.
3. A small numerical example, explaining every symbol, dimension, unit, denominator and assumption before larger syntax.
4. A second, changed-condition example showing where the first intuition fails.
5. Predict → Experiment → Observe → Explain → Apply; prediction is recorded before reveal, not required to be initially correct.
6. Trusted notebook implementation with explicit training/evaluation boundaries, followed by a reduced-scaffolding challenge.
7. Failure modes, alternatives, targeted feedback and objective-level practice.

This maps the existing twelve-part algorithm contract: problem/use case, intuition, mathematics, stepwise mechanism, experimentation, Python, hyperparameters, evaluation, failure modes, alternatives and independent challenge. “Use case” includes when **not** to use the algorithm. The matrix supplies worked seeds, not finished lesson copy; full teaching quality remains implementation acceptance, not a claim that tables teach these lessons already.

## Mathematical and library conventions

- Existing unregularized loss/update runtimes never change. Specify loss normalization separately for each new model. With n training rows, residual vector r=y−Xw and unpenalized intercept: Ridge uses ||r||²+α||w||²; Lasso uses ||r||²/(2n)+α||w||₁; Elastic Net uses ||r||²/(2n)+αq||w||₁+α(1−q)||w||²/2. q is the mixing fraction. Equal α across these conventions does not imply equal strength. Standardize within training/folds where appropriate. Numerical solvers, not matrix inverses, fit practical models. [Linear-model reference](https://scikit-learn.org/stable/modules/linear_model.html).
- Logistic outputs probabilities through a sigmoid; thresholds choose actions, not coefficients. KNN uses training examples and an explicitly defined metric/vote/tie policy. Gaussian and Multinomial NB have different likelihood assumptions; neither licenses causal conclusions. [Neighbors](https://scikit-learn.org/stable/modules/neighbors.html), [Naive Bayes](https://scikit-learn.org/stable/modules/naive_bayes.html).
- Tree regression uses squared-error leaf means; classification uses weighted impurity and class frequencies. Forest classification averages tree probability vectors before choosing a class. Boosting regression's squared-loss residual story must not be presented as the complete classification algorithm: classification follows loss gradients. [Trees](https://scikit-learn.org/stable/modules/tree.html), [ensembles](https://scikit-learn.org/stable/modules/ensemble.html).
- SVM margins are not calibrated probabilities. Intro MLP covers a small feedforward classifier, nonlinear activations and one trusted gradient step; nonconvex fitting is not guaranteed to find a global optimum. No advanced deep-learning course is added. [SVM](https://scikit-learn.org/stable/modules/svm.html), [MLP](https://scikit-learn.org/stable/modules/neural_networks_supervised.html).
