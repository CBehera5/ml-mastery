## Geometry and support membership

F=w·x+b;F=0 is a boundary. Signed point distance F/norm(w),unsigned abs(F)/norm(w),signed class margin yF/norm(w),functional margin yF and hinge max(0,1−yF) are different quantities. Canonical F=−1,+1 slab width2/norm(w) is a true geometric width in the declared fitted feature coordinates,not an arbitrary plotted pixel width. SV-E1 linear fits use raw coordinates;SV-E2 linear baselines use the same training-standardized nonlinear data as their RBF counterparts. Manual w,b scenes are explicitly NOT fitted optima. w,b rescaling preserves point-to-boundary distance but changes unnormalized scores and canonical slab width. A zero normal yields tagged undefined distances/width,not0;manual support membership is tagged unavailable because no solver was run.

Soft-margin primal objective=.5*norm(w)^2+sum_i C_i*hinge_i. C_i=C*class_weight[label_i];larger C raises violation penalties relative to norm regularization. Do not call larger C stronger norm regularization or promise monotonic validation improvement/margin changes. Hard margin is a contextual separability constraint,not a separately fitted model here.

Support IDs are EXACT sklearn support_ entries;do not remove small positive coefficients with a display threshold or identify supports solely by distance. Alpha tolerance1e−7 classifies KKT diagnostics as zero/free/at-bound only;it does not redefine exported solver support IDs. Support vectors may lie inside the margin or be misclassified;degenerate on-margin rows may have zero alpha. Dual feasibility,sum(alpha*y)=0,box bounds,KKT conditions and primal/dual objectives are independently checked. Maximum permitted KKT violation1e−4;primal-dual gap must be no more than1e−4*max(1,primal),not an assertion of exact symbolic optimality.

## Kernel,scaler and solver

Linear kernel is dot product. RBF=exp(−gamma*sum squared fitted-coordinate differences). C∈{.1,1,10};RBF gamma∈{.1,1,4};linear gamma1 is recorded but ignored by that kernel. Scaling is either identity or StandardScaler fitted on training IDs only,population variance ddof0 and constant-column scale1. No global/fold-validation/test statistics are permitted. RBF data's second coordinate is expressed100 times larger to expose unit sensitivity;changing numerical units is not a new observed risk factor. Similarities are not measured input columns or calibrated probabilities.

All fits use pinned SVC,probability=False,shrinking=False,tol1e−6,cache64MB,max_iter200000,decision_function_shape='ovr',break_ties=False,random_state1729. Binary decision shape ignores multiclass OVR machinery;no multiclass expansion. No sample weights. Unweighted states use class_weight=None. Two extra noisy/scaled C1,gamma1 states use training-count-derived balanced weights and explicit {0:1,1:3} weights respectively. Balanced weights are n_train/(2*n_class) from training only;no validation frequency or resampling. Every fitted state must have fit_status_=0;nonconvergence is a verification failure,never certified as an optimum. During authoring,a same-dataset linear comparison hit the iteration cap with an excessively strict1e−10 stopping tolerance;that draft was not frozen. The final1e−6 tolerance is explicit and all independent score/KKT/gap acceptance checks remain unchanged.

Approved CPython3.13.16,NumPy2.5.4,pandas3.0.6,Matplotlib3.11.2,scikit-learn1.9.1,SciPy1.18.1 on the recorded local macOS ARM64 environment. Explicit probability=False emits the pinned library's probability-parameter FutureWarning;it is expected and recorded,not suppressed or a probability fit. No predict_proba or calibration method is called. random_state affects probability estimation's shuffling when enabled;with probability disabled it does not itself supply stochastic training diversity. Reproducibility relies on fixed rows/order,settings and versions,not a misleading seed guarantee.

## Scores,labels and boundaries

Manual and fitted scores are reconstructed from coefficient/intercept or dual coefficients and pairwise kernels. Fitted binary scores>=0—including exact signed zero—map to class1 in the pinned SVC reference;negative maps to class0. Every exported prediction is checked against the native decision-score sign. Manual geometry labels exact F=0 as on-boundary instead of assigning a fitted prediction;this is an intentional educational distinction,not another class.

Independent kernel summation and native solver arithmetic may differ at tiny scores. abs(manual_score)<=1e−9 is reported as near-boundary numerical sensitivity,not rounded to zero and not used to override actual native classes. Native classes remain authoritative for those rows;manual and native scores must still agree within1e−9 absolute/relative. Away from that band,manual sign must also match prediction exactly. A raw score and sigmoid(score) are NOT automatically calibrated probabilities. RBF scores are not Euclidean distance to a straight line in raw input space;export RKHS norm/dual checks without inventing an input-space margin width.

Visualization uses25 fixed query points plus at most12 training and6 validation points,43 total;no21×21 mesh or unreviewed continuous boundary coordinates. The sparse class/score samples demonstrate local structure,not an exact continuous contour. Tables and textual query outcomes remain available without plots. Any future boundary path must be separately reviewed against the frozen query evidence;do not invent exact paths by connecting sparse classes. Immutable training-kernel matrices are reference assets,not learner-submitted arrays;chunk displayed matrices into panels of at most8 columns and32 rows rather than relaxing table/answer bounds.

## Evaluation and rejection

Training IDs alone fit scaler,SVC and training-count weights. Development selection maximizes validation balanced accuracy among the manifest's fixed fitted candidates PER fictional fixture. Within absolute1e−12 of the best score,ties choose the first candidate in the frozen ordered list (C .1→1→10,gamma .1→1→4,raw then scaled;extra weighted scenes followed by same-dataset linear baselines appended). This is an auditable tie rule,not a proof the first candidate is universally simplest. Accuracy and confusion matrices are also reported;no probability metric or calibration claim.

Validation selection is separate from final evaluation;sealed test arrays are offline metadata,never predicted,evaluated or used to select C,gamma,scale,weights or boundary. Future application replay must strip sealed test metadata. No CV fitting is claimed by these experiments;SV04 still requires fold-only teaching/assessment and the future notebook must demonstrate independent fold fits. An invalid global-scaling scene illustrates precisely why training-only outer preprocessing is not fold-only fitting.

Reject before fitting/replay:SV-E1 nonpositive-C,nonfinite-boundary,test-tuned-boundary;SV-E2 nonpositive-gamma,globally-fitted-scaling,test-tuned-C-gamma. Null score/prediction/support IDs with tagged invalid outcome,not fabricated0. Unknown IDs,unsafe expressions,unapproved kernels/C/gamma/scaling/weight combinations or oversized input are unsupported. Only listed configurations are exposed;there is no arbitrary model/expression evaluator. The diagnostic author records describe rejections,not an implemented application validator.
